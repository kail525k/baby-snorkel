# 아기 스노클링 바다 여행

제주 · 강원 동해안 · 미야코지마 바다를 아기 캐릭터로 스노클링하는 3D 웹 게임이에요.

- 게임은 `index.html` 파일 하나로 돌아가요 (three.js, supabase-js는 CDN에서 불러와요).
- 같이 수영하기와 잠수·서핑 순위는 Supabase(welev-games 프로젝트)를 써요.
- Vercel에서 이 저장소를 가져오면 별도 설정 없이 배포돼요. 프레임워크는 "Other"를 고르면 돼요.

## 하늘 (패러글라이딩) — `sky.js`
- 하늘 장소는 `index.html`의 `SKY_SPOTS`(kind: 'sky')에 따로 정의해요. 첫 장소: 단양 양방산 활공장(`danyang`).
- 하늘 월드(지형 · 남한강 · 단양읍 · 강변 아기마을 · 비행 · 탈것 · 버스 · 업히기)는 `sky.js`(ES 모듈)에 있고, 하늘에 들어갈 때만 불러와요. 바다는 `sky.js` 없이도 그대로 돌아가요.
- 렌더러 · 아기 · 진주 · 매점 창 · 순위 창 · 토스트 · 소리 · 같이 놀기(장소별 방 `spot-danyang`)는 바다 것을 함께 써요.
- 착륙 점수 ÷ 10(반올림) = 진주 (`PEARL_PER_SCORE`). 테스트용 진주 버튼은 주소에 `?test=1`이 있을 때만 보여요.
- 하늘 순위는 Supabase `snorkel_submit_sky` 함수가 필요해요(마이그레이션 적용 전에는 내 기록만 보여요).

## 바다 놀이 더하기 — `index.html`의 "바다 놀이 더하기" 구역
- 부딪히면 통!: 친구 · 바다 친구(AI) · 보트와 부딪히면 서로 튕겨 나가요. 하늘에서도 친구 · 마을 사람 · 안전요원(AI) · 튼튼이와 부딪히면 튕겨요.
- 큰 파도: 70초마다 한 번꼴(실제 시계 기준이라 친구도 같은 파도를 봐요). 물에 있으면 파도를 타고 해변 쪽으로 밀려가고, 물가 모래성은 쓸려 갈 수 있어요.
- 화면에서 튜브 · 평상 · 보트 같은 자리를 누르면 "물멍하기" → "물멍하러 가기"로 걸어가서 앉아요. 막히면 순간이동해요.
- 절벽 다이빙: 깊은 물 옆 높은 바위(9m 이하)를 바다마다 찾아 빨간 깃발과 "다이빙 바위" 표지판을 세워요. 성공하면 높이만큼 진주(1~5, 바위마다 60초에 한 번).
- 모래 놀이(마른 모래 위에서): 모래성 만들기(4단계, 완성 시 진주 +2) · 모래에 눕기 · 모래찜질. 모래성과 모래찜질은 친구 화면에도 보여요.
- 상어(만화처럼, 다치지 않게): 깊은 곳을 빙글빙글 돌다 가까이 오면 다가와서 쿵 부딪혀요(넘어지고 들고 있던 간식을 가져가요). 물총으로 맞히면 도망가요(진주 +3).
- 보트: 해변 가까이 매어 둔 보트를 E(폰은 주황 버튼)로 타고 내려요. 보트 위는 상어에게 안전하고, 친구 화면에도 보여요.
